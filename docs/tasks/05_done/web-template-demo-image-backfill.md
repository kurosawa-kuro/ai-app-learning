# 投稿サンプルの不足画像を補完

2026-10-27。ユーザーの投稿画像が反映されていないという指摘を受け、稼働中の開発アプリ8080を確認。

- 既存サンプル8件は画像なし。追加されたユーザー投稿1件は画像取得HTTP 200・一覧と詳細でデコード成功。
- 原因：画像OFF時のシードを維持したまま、画像許可ON後の既存サンプル補完を行っていなかった。従来の追加シードも既存IDをスキップしていた。
- `seed-images` を追加。画像対象の固定サンプルID2件にだけ、未登録画像を添付する。本文・タイトル・ユーザー投稿・既存画像を保持。DBの条件付きUPDATEで競合時の上書きを防ぎ、採用されなかったアップロードは後片付けする。
- Java 34件成功。未添付補完・再実行・設定OFF・画像保存失敗を検証。
- 実データへ実行：9投稿・3ユーザーを維持、画像付き1→3件、削除待ち0件。
- 実アプリの読取検証 `tests/post-images-preview.cjs` が成功。画像対象2投稿の一覧・詳細をPC1280pxとスマホ390pxで確認し、実画像の自然幅も検査。スマホ詳細のスクリーンショットも目視確認。
