## 読み方と管理方針

個別アプリの現行仕様・開発・公開手順は、各READMEから正本をたどる。全体方針は個別仕様を上書きしない。**実装・検証・公開の状態、学習到達目標、未採用の拡張案、事業仮説を分けて管理する。**

キャスト評価はナイトワーク特化の1パターンのみ。将来2パターンに分離する余地だけ注記し、第2パターンの文書・仕様は作成しない。

本一式は分割文書パッケージから `src/gas-app-learning/docs/` に配置された資料。このREADMEは文書索引、アプリ集の入口は1階層上のREADMEとする。個別アプリは1階層上の各プロジェクトを参照し、現行仕様はそこで管理する。
