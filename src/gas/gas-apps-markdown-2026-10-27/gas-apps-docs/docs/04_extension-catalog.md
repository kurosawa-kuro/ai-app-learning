### 現行仕様と混同しない点

- **skill-janken**：管理画面でのAIセリフ事前生成は既存の機能。「AIなしから後で初めてAIを追加」は現行アプリ全体の説明ではない。ゲーム本体のルール処理と、追加候補の攻略・行動提案を比較する教材案として扱う。勝敗判定や得点をAIに委ねる変更、リアルタイムAI対戦は採用していない。
- **英語訓練**：AI採点・会話は既存の中心機能。弱点に応じた出題・問題生成等は、それらとは別の候補。全教材に一律の「まずAIなし、後からAI追加」という構成を適用しない。
- **写真日記**：複数タグや日記と写真の関連は既に扱っている。既存機能を新規拡張と数えず、改善したい点を具体化する。保存後の編集・削除は現行範囲外。
- **キャスト評価**：現在はルール変更時に過去期間も再計算し、ルール履歴・過去結果の固定保存は行わない。適用期間や履歴の追加は、データ・計算・過去結果の意味を変える別の仕様変更。AIの説明や提案を、評価点の自動決定や設定への自動反映と同一視しない。
- **EC**：注文整合性は基本機能でも守るべき条件であり、拡張まで後回しにしない。注文全体のキャンセルは既存の設計範囲。在庫引当・決済連携は現行初期範囲外で、このメモでは採用しない。

### 拡張課題を作る場合の書式案

採用を検討する課題ごとに、対象プロジェクト、学習目的、前提知識、追加機能、データモデルへの影響、変更してはいけない既存機能、AIへの依頼例、受入条件、模範実装と比較する観点を整理する方法が考えられる。現時点で全課題の作成や模範実装を必須にはしない。

参考例として「skill-jankenのAI攻略アドバイザー」を検討するなら、次のような確認観点がある。

- AIに渡す状態・履歴と、返してよい提案の範囲を定義する。
- 提案と理由を表示し、勝敗判定・既存のゲーム状態を変更させない。
- 提案失敗や不正な行動の提案でもゲームを継続できることを確認する。
- 追加したアドバイザーを無効にしても、元のゲームが成立することを確認する。
- APIキーを公開せず、呼出回数や費用の扱いを決める。
- 現行CPUの仕組みに照らし、根拠のない必勝策や優位性を説明しない。

これも課題の採用決定や実装要件ではない。子供向けの利用形態、大人の伴走、現在の自由入力・公開範囲の制約も含め、採用する場合に具体化する。

### 採用へ進める場合

必要性や学習効果を確認した候補だけを、ポートフォリオの役割分担・現行仕様・保守負担と照合する。その後、個別プロジェクトで範囲・受入条件・仕様変更を決定する。ここに記載しただけでタスク化・開発着手・販売案内へ進めない。

基本仕様（Core Specification）、展開案（Extension Roadmap）、演習一覧（Exercise Catalog）を分けて管理する方法も参考案として保持する。今回の文書分割では本カタログに候補を集約した。個別教材に基本仕様・演習一覧等を新設するかどうかは、別途判断する。

すべての候補に模範実装を用意する必要はなく、採用した代表課題だけを例示し、他は学習者が考える余地として残す方法もある。採用しない、簡素化する、後で見直す選択を残す。

## 共通の追加機能案：AI 利用金額

AI を利用する各アプリで、利用ごとの金額・今月の合計・累計を確認できるようにする構想。元のメモを横断的な追加機能案として整理したもので、各アプリへの実装済み要件ではない。

| 項目 | 表示・記録する内容の案 |
|---|---|
| 利用ごとの金額 | 1 回の AI 要求に対応する利用量と推定金額 |
| 今月の使用金額 | 定義した月の範囲に含まれる要求の推定金額合計 |
| 累計の使用金額 | 記録開始以降の推定金額合計 |
| 根拠 | 実行日時、アプリ、要求 ID、モデル、入力・出力等の利用量、適用単価と通貨 |
| 成否・不明状態 | 成功・失敗・結果不明と、利用量を取得できたかどうか |

初期設計で揃えること：

- 月の区切りは Asia/Tokyo を候補とし、集計対象の利用者・アプリ・記録開始日を定義する。
- 推定金額とプロバイダーの請求額を区別する。単価・モデル・料金の適用時点を記録し、実装時に公式の料金情報を確認する。
- 同じ要求 ID の結果再取得を新たな AI 利用として二重計上しない。実際に追加の API 呼び出しが発生した場合は、その実行を区別して記録する。
- 結果不明や利用量未取得を 0 円とみなさない。未集計件数などで不完全な集計だと分かるようにする。
- 表示機能と、利用上限・警告・課金停止は別機能として扱う。

現時点の対象候補は写真日記・英語訓練・じゃんけんの管理画面での AI 利用。EC とキャスト評価の初期仕様には AI 機能がないため、金額表示のためだけに AI 機能を追加しない。
