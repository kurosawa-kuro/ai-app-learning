# ③の運用

状態：内部手順。2026-10-28。公開未実施。

1. [設計](site-design.md)に沿って、中立的な紹介・利用例を編集する。
2. [制作入力の手順](../../../publishing/README.md)に従い、`--site alias-general` で検査する。①の未完成は③の編集を妨げない。
3. 活動名・ブランド・専用連絡先を設定し、①の本名や②の活動名を自動継承しない。
4. 本名・専門情報・他出口へのリンクが、原稿・画像・取得物・検索・添付・返信に出ないことを確認する。
5. 公開準備チェックの後、生成・配置・実環境受入を別途行う。現時点で生成・配置の自動処理はない。

メール・署名・会議・共有資料の表示も③専用にする。全商品一覧を返信に添付しない。共通要件は[分離ポリシー](../separation-policy.md)。

## 将来の整理

①完成時にも③を自動終了しない。中立本文の再利用、旧URLの維持・終了、検索、配布資料、問い合わせ窓口を個別に決める。本名との対応を明かす転送・告知・canonicalは自動設定しない。顧客情報や問い合わせ履歴も自動移管しない。

決定した対象・版・対応日を内部の作業記録へ残す。③のIDを別用途の出口へ使い回さない。
