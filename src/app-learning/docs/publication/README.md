# 情報出口の設計・運用

状態：内部管理の正本。2026-10-28更新。公開サイトには配信しない。

名刺の先行準備は[WIP公開・印刷運用](wip-release.md)を参照。3サイトは標準URLでWIP公開済み、①の独自ドメインはDNS待ち。教材配布の公開無効とは区別する。

当面は3出口を管理する。**本名の公開範囲と、扱う題材を別の軸にする。** 既存アプリのコード・仕様は移動・複製しない。

| 出口ID | 本名 | ナイトワーク | 位置付け |
|---|---|---|---|
| `realname-general` | 公開 | 扱わない | ① 準備に時間をかける本名サイト |
| `alias-nightlife` | 非開示 | 扱う | ② 写メ日記・キャスト評価を推す |
| `alias-general` | 非開示 | 扱わない | ③ 本名サイトの完成を待たずに準備する一般向け |

公開名・連絡先の実値は未設定。②と③は別の活動名にすることをユーザーが確定した。設定・プロフィール・窓口も別々に持ち、相互リンクを作らない。①は独自ドメイン必須、②・③は必須ではなく簡易サービスでもよい。公開技術はできるだけ共通にする。将来の2出口化は①・②を基本想定とし、③の終了・内容移管を別途判断する。

## フォルダーの役割

```text
src/app-learning/
  01-gas-app-learning/                 既存コード・個別仕様
  02-web-app-learning/                 既存コード・個別仕様
  docs/
    publication/
      separation-policy.md            共通の確定要件
      realname-general/               ① 内部設計・運用
      alias-nightlife/                ② 内部設計・運用
      alias-general/                  ③ 内部設計・運用
  publishing/
    catalog.yaml                      全素材の公開許可・依存物
    common/content/                   中立的な公開本文
    realname-general/                 ① 原稿・素材・設定
    alias-nightlife/                  ② 原稿・素材・設定
    alias-general/                    ③ 原稿・素材・設定
    scripts/                          設定・分類・リンク検査
    dist/                             将来の生成物。Git管理外
```

各出口は `content/`、`assets/`、`samples/`、`publish.yaml` を持つ。`assets/`・`samples/` は素材未登録で、空の位置を示す `.gitkeep` だけを置く。`.gitkeep` は公開素材ではない。内部の本名対応表・秘密値・実店舗データはこのツリーに入れない。

## 実施した範囲

内部設計・運用、3出口の設定、最初の紹介原稿、素材台帳、ローカル検査を整備した。設定検査は公開サイト・認証・デモの動作確認ではない。公開名・連絡先・専門側の公開水準、実際のサイト生成・配置は未設定／未実装であり、全出口で公開を無効にしている。

制作リポジトリの公開範囲は別途確認が必要。フォルダー名でアクセス権限が分離されるわけではない。全内容を扱える内部担当者だけが制作元を利用し、一方だけを扱う外部担当者には選別した素材だけを渡す。
