# ①の運用

状態：内部手順。2026-10-28。公開未実施。

1. [設計](site-design.md)と個別アプリの正本を確認し、専用原稿を編集する。
2. [制作入力の手順](../../../publishing/README.md)に従い、`--site realname-general` で検査する。①の準備中でも他出口の検査は独立して行える。
3. 本名を公開する表記・ブランド・問い合わせ先を決める。個人用メールや他出口のプロフィールを既定値として埋めない。
4. 一般向け成果物の画面・検索・取得物・添付・返信に専門情報が出ないことを確認する。
5. 公開準備チェックに加え、生成・配置・実環境の受入を別途行う。現時点で生成・配置の自動処理はない。

問い合わせ・返信・署名・会議は①用として管理し、②・③の対応履歴を共通の商品案内として転送しない。共通要件は[分離ポリシー](../separation-policy.md)。

公開後の変更は正本から修正し、生成物だけを直接直さない。版と配置先を記録して安全な版へ戻せるようにする。③を①へ自動転送しない。
