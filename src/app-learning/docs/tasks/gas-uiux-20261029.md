## ローカル受入

5教材の実装とローカル受入は完了。Nodeの単体・回帰試験は合計258件成功（日記163、英語76、評価7、ショップ8、じゃんけん4）。日記・英語は `npm run check`、じゃんけんは `npm run check`、評価・ショップは `npm test` と `npm run format:check` を実施した。

ブラウザーは実Chromium、GAS・Sheets・Drive・OpenAI通信は模擬。評価4・ショップ4・じゃんけん4ケース、日記・英語は各PC1440／狭幅390pxの通し受入に成功。日記は画像読込失敗・再試行の既存受入も成功した。

- 英語：未送信回答がある状態で次の問題への移動を取消→問題・回答を保持。遅延応答中の回答読取専用・タブ切替停止・処理表示、成功後の回答と評価の対応を確認。会話・終了・履歴、結果不明の中止と回復も既存受入で成功。
- 評価：区画切替後の入力保持、保存後に対象月の結果を表示、5.00 pt・重複拒否・再読込を確認。メンバー保存後に応答だけ失わせ、入力固定→同一要求再送でメンバー1件を確認。
- ショップ：1800円の確認→数量を保って戻る→確定→保存明細→再読込→注文者切替を確認。応答消失時は数量変更へ戻れず、同一要求再送で注文1件を確認。
- じゃんけん：対戦結果→「もう一度遊ぶ」→未選択へ戻りフォーカス復帰。応答消失時は手を固定し、同一要求再送で履歴が1件だけ増えることを確認。
