# CR版のエラーと再試行

- 入力範囲・日付・対象IDをサーバーで確認する。知らない操作名は実行しない。
- 入力や参照の誤りは日本語の理由を表示する。それ以外は秘密やスタックを出さず、保存・読込失敗として知らせる。
- 通信・保存失敗時にフォームを消さない。送信中は操作を無効化する。
- 同じ入力の再送IDを画面内で保持する。成功を受け取るまで同じIDで再試行する。画面を閉じた後まで永続化しない。
- 初期化時の表・列不一致は処理を停止する。既存データを自動消去・再作成しない。
- 一括復旧UI・監査ログDB・定期処理は作らない。保存途中の扱いと限界は[データ設計](05_data_model.md)を参照。

実際に保存されたか不明な状態で画面を閉じた場合は、再登録する前にSheetsと一覧を確認する。
