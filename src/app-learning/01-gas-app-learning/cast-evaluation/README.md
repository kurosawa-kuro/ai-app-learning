## まず試すこと

2026-10-29のUIUX改善では、月次結果・実績入力・メンバー・配点を切替表示し、区画の移動では入力を保持する。月次結果は対象月付きの比較表で、実績数量・点数・順位を並べる。保存結果が不明な間は入力を固定して同じ要求で確認する。メンバー追加時は書きかけの実績の対象者を変更しない。公開版・検証の最新状態は[思想別UIUX受入](../../docs/tasks/gas-uiux-20261029.md)を参照。

メンバーを追加し、ドリンク2・ボトル1・指名0・同伴0・売上12000円を保存すると **5.00 pt**。同じ人・同じ営業日の再登録は拒否する。

## 起動・テスト

このディレクトリで実行する。Node.jsはローカル検証用で、GAS実行には不要。Node 24で確認。

```bash
npm ci
npm test
npm run dev
# 別ターミナルではなく、devを止めてからブラウザテストを実行
npx playwright install chromium
npm run test:browser
npm run format:check
```

ローカル画面は `http://127.0.0.1:8192`。サーバー停止でメモリ内データは消える。GASへは[公開手順](docs/08_release_runbook.md)で配置する。Makefileの雛形は検証に使わない。

## コードの読み方

| ファイル | 役割 |
|---|---|
| `src/application.js` | 表定義・初期データ・業務処理 |
| `src/store.js` | Sheetsの読取り・追記・初期化 |
| `src/web.js` | HTML配信と操作名を限定したRPC |
| `src/index.html` / `src/app.html` | 入力・結果表示 |
| `src/bridge.html` | 通信、送信中表示、再送ID |
| `src/style.html` / `src/pico.html` | 同梱Pico CSSとレイアウト |

共通の保存・通信・見た目の小さな実装を2教材で揃え、各アプリ単独で配置できる。外部の共通ランタイムは導入しない。
