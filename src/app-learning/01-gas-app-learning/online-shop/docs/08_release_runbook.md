通常Chromeでの接続・承認・操作確認は[Playwright実環境検証手順](../../../docs/runbooks/gas-playwright-chrome.md)を参照。

## 最初の1コピーを用意する

1. 教材専用の新しいGoogleスプレッドシートを作る。他アプリのSheetsを流用しない。
2. そのSheetsの「拡張機能 → Apps Script」を開く。
3. `src/`のJS3ファイルを同名のスクリプトファイルとして追加（エディターでは.gs）。HTML5ファイルを拡張子を除いた同名で追加する。初期の空Code.gsは不要。
4. プロジェクト設定でマニフェストを表示し、`src/appsscript.json`を反映する。
5. エディターで`initializeApp`を一度実行し、Googleの権限確認を行う。必要なシートと架空の初期データを作る。再実行では既存データを上書きしない。
6. Webアプリとして新しくデプロイ。「実行するユーザー：自分」「アクセスできるユーザー：自分のみ」。`/exec`のURLで開く。アプリ独自の認証は作らない。
7. 下の項目を実際に試し、コピー先・確認日・結果を記録する。Googleアカウントや鍵を文書へ載せない。

CLIで配置する場合は、既存の空のバインド先Script IDを使う`.clasp.json`をこのディレクトリへローカル作成する（Git対象外）。`rootDir`は`src`。例：

```json
{ "scriptId": "新しく作った教材専用Script ID", "rootDir": "src" }
```

認証済みclaspの`clasp show-file-status`で対象を確認し、`clasp push`で配置する。既存アプリへ誤ってpushしない。`.claspignore`はrootDir基準でsrc直下のJS・HTML・manifestのみ許可する。[clasp公式](https://github.com/google/clasp#ignore-file-claspignore)（2026-10-28確認）。CLIの導入はGoogleエディターでの配置に必須ではない。
