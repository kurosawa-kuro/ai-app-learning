# CR版の検証

## ローカルで確認した範囲（2026-10-28）

- `npm test`：8件成功。実際のapplication.js/store.js/web.jsをVMで実行し、GAS APIだけを模擬する。
- `npm run test:browser`：4ケース成功。Chromium、PC 1440px／スマホ390px。フォーム入力・保存・再表示・エラー・横はみ出しを確認。
- スクリーンショットは`test-results/`以下。テスト実行時に生成し、Gitへ含めない。実際に開いて幅・文字・操作位置を確認する。
- 入力検証・再送・途中失敗・初期化の非破壊性を確認。ショップは1800円、評価は数量配点・月合計売上の切捨て・同順位を固定例にする。

## 別途必要な実GAS受入

模擬APIではOAuth、Google権限、実Sheetsの型・書込み、HTML Serviceのiframe、割当制限・通信時間は保証できない。[公開手順](08_release_runbook.md)のチェックを新しいコピー先で実施して記録する。既存の本人限定@1では主要操作を確認済み。Sheets行の直接照合・初期化再実行後の保持は未確認。新しいコピー先の受入は別途必要。

ローカルの速さを実GASの計測値として案内しない。CR版の成功を旧MVP全機能の完成と扱わない。
