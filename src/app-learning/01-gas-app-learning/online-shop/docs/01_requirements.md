# CR版の要件

2026-10-28の最新指示により、GAS本体がなかった2教材のCreate／Readを先行する。仕様の正本はREADMEから参照する基本仕様の先頭。旧MVP全体の完了は求めない。

## 目的と範囲

商品と数量の指定・直接注文の作成・注文一覧・注文明細の読取り。身近な入力を保存し、その結果を読み返して、Web版とデータ関係を比較できること。

注文取消、カテゴリー管理、商品／ユーザーの管理画面は後続。AI・独自ログイン・監査・復旧管理は今回追加しない。選択ユーザーは架空の操作対象であり本人認証ではない。

## 最初の成功条件

1. 架空データから対象者を選ぶ。
2. 期待結果をメモして1件登録する。
3. 一覧・詳細／月次結果と保存先の行を照合する。
4. 再読込して同じ内容を読み返す。

入力エラーと保存失敗は理由を表示し、入力を残す。同じ送信の再試行を別の登録にしない。スマホでもPCと同じ順で操作する。最初の1課題でAIに依頼し、結果を確認できればよく、全教材の修了や業務運用を要求しない。

現在はローカル検証まで。[実GAS受入](08_release_runbook.md)は未実施。[データ設計](05_data_model.md)と[検証方針](07_test_strategy.md)を参照。
