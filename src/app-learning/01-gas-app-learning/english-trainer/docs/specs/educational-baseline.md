# 英語教材の基本配布範囲

2026-10-28。個人用のクイズ・AI採点・テキスト会話・振り返り・学習履歴で完成とする。WebとGASで基本体験を揃え、資格学習への変更は目標提案・参考プロンプトとして扱う。

## 基本導線

1. 初回に設定で本人のOpenAIキーを登録し、AI利用を有効にする。キーはScript Propertiesだけに保存する。
2. 「練習」で1問を開き、自分の英文を書く。AI送信を確認し、採点結果を読む。
3. 「会話」で短い自由会話をする。終了時の振り返りを読む。
4. 「記録」で回答・採点・会話履歴を確認する。

自由記述クイズと自由会話を既定にする。能力一覧、表現候補の承認、再学習リセット、複数シナリオ、選択式を基本画面へ並べない。問題管理・音声入出力・資格教材の完成品は追加しない。

## 保持するもの

旧G3の教材51件、回答と採点時点の版、会話履歴、同ID再送と結果不明時の停止処理は保持する。既存データを削除して画面を簡単に見せる変更はしない。旧保留問題を復元できる選択肢や内部処理は互換用に残っており、コード全体を削除したという意味ではない。

通常の採点結果を見た直後に再採点ボタンを出さない。採点結果がない自由記述の記録のみ再試行の入口を残す。操作が失敗した場合の入力保持・説明は基本体験に含む。

2026-10-29：未送信回答がある状態で次の問題へ進む際は破棄確認を行う。送信・生成処理中は回答・メッセージを読取専用にし、タブ切替も止めて処理状態を表示する。採点成功後は送信した回答を評価と一緒に示し、回答欄を固定する。次の問題で新たな回答を開始する。通常のタブ切替では下書きを保持し、会話終了・別会話の開始時も未送信文を確認する。[思想別UIUX受入](../../../../docs/tasks/gas-uiux-20261029.md)で公開・検証範囲を管理する。

データ構造・再送・回復の詳細は[G3内部仕様](gas-trainer-v1.md)、初期設定と実環境受入は[Runbook](../08_release_runbook.md)。製品の範囲は本書を優先する。

## 小さな横展開の例

「この英語クイズの仕組みを、資格の用語問題に変えたい。最初の1問だけを例に、問題・模範回答・採点の指示で何を変えればよいか提案して。回答履歴を残す仕組みは維持して」

本人が1問を試し、採点の妥当性を確認できれば初回の成功。教材全部の習得や、追加アプリの制作を必須にしない。
