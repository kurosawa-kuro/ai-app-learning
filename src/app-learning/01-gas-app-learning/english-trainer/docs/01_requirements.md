# 要件

現行の実装範囲は[G3仕様](specs/gas-trainer-v1.md)。現在の基本導線は自由記述AI採点、短い自由会話、振り返り、記録、設定。旧G3の会話3種・候補承認を基本体験の必須条件にしない。教材編集は利用者のSheetsで行う。AIオフでも回答を保存し、後から再判定できる。

1人1コピー・各自のOpenAI APIキーを前提とする。入力には個人情報・機密情報を含めず、外部送信に同意する。G4と音声は範囲外。本人限定@3の主要操作は確認済み。キー再登録・コピー配布などの残項目は[受入記録](../../../docs/tasks/gas-release-20261028.md)と[公開手順](08_release_runbook.md)を参照。
