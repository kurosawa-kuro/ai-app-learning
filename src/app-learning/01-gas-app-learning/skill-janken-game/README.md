# skill-janken-game：GAS通常じゃんけん

GAS版は「手を選ぶ→勝敗と得点を見る→履歴を読む」の小さな教材です。スキルとAIセリフはWeb版で体験します。

現行仕様は[通常じゃんけん](docs/specs/gas-basic.md)。`src/basic/`の9ファイルだけを配布します。旧スキル版のソース・文書・既存クラウドは保管し、新しい専用Sheetsを使います。

## 実行

```powershell
npm ci
npm run check
npm run preview
```

checkはビルド・業務テスト・整形・PC／スマホのPlaywright検証です。previewは模擬GAS・メモリ保存で、画面にもその旨を表示します。実Sheetsへの配置は[手順](docs/specs/gas-basic.md#検証と配置)に従います。

## 学ぶこと

- 条件分岐で勝敗を決める。
- プレイヤー1人に複数の履歴がつながる。
- AIに得点変更を依頼し、期待した結果になるか確かめる。

全員がWeb版へ進む必要はありません。この1つでAIとの並走を体験できれば初回の成功です。
