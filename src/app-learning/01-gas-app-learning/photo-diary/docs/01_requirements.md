# 01 要件

[README](../README.md)・[CLAUDE](../CLAUDE.md)・[AGENTS](../AGENTS.md) を基準に整理した現在の MVP 要件（2026-10-24）。

## 目的と利用者

Google Apps Script と Google Sheets で写真・キーワード付きの日記を作り、1 対多・多対多の関連とウェブアプリ開発を学ぶ。一次ユーザーは、本人のみ公開のアプリを使う所有者・学習者。

## 範囲

| 機能 | 現在の範囲 |
|---|---|
| 一覧 | 新しい順のカード表示、キーワードによる絞り込み |
| 作成 | 写真・キーワード選択、下書きの取得・編集、タイトルと本文の保存 |
| 詳細 | 写真・本文・キーワード表示、キーワードから一覧への移動 |
| 写真 | 提供元の目録から選択し SVG を表示するダミー |
| AI 下書き | Geminiでキーワード・登録画像から生成。文体設定を適用。無料枠の送信確認を設ける |
| 保存 | posts・images・tags・post_tags と uploads・requests の6シート |
| 計測 | 一時的な #perf 画面と計測 API が残る |

編集・削除・独自ログインは MVP の対象外。Google Drive 連携、Gemini 連携、英語日記、業務転用は将来構想であり実装済み要件に含めない。UI は明るい配色のみで、アニメーションは未着手。

## 中核の利用手順（Golden Path）

完了状態は、選んだ写真とキーワードを持つ日記が保存され、詳細と一覧から確認できること。

| # | 操作 | 成功条件 |
|---|---|---|
| 1 | アプリを開き一覧を確認、キーワードで絞り込む | 新しい順の一覧と、選択したキーワードに対応する日記が表示される |
| 2 | 作成画面で写真・キーワードを選び、下書きを取得して編集する | 下書きのタイトル・本文が入り、利用者が修正できる |
| 3 | 保存する | 日記が 1 件作成され、写真・タグの関連が保存される |
| 4 | 詳細を確認し、一覧・絞り込みへ戻る | 本文・写真・キーワードが一致し、作成した日記を再確認できる |

同一 requestId の再送による二重登録防止、不正な入力・参照先の拒否、通信失敗の表示も維持する。ロックとキャッシュには有効期間・実行環境の制約があり、データベースのトランザクションと同等の保証とは扱わない。
