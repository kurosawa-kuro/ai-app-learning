# Evidence Policy — photo-diary

完了の根拠は実ファイル・コマンド出力・実際の操作結果。基準は [AGENTS.md](../../AGENTS.md) と [テスト戦略](../07_test_strategy.md)。

| Level | 証拠 | このプロジェクトで示せること |
|---|---|---|
| 0 | 主張のみ | 完了の根拠にしない |
| 1 | 文書・パス・リンク・内容の静的確認 | 文書のみの整合修正を検証できる |
| 2 | npm test の生成と全テスト成功 | 模擬 GAS / jsdom を含むローカル検証の成功 |
| 3 | GAS のテスト環境等で操作し保存・再表示を確認 | 実際の実行環境での動作。公開版の更新とは区別 |
| 4 | 既存の公開 URL で一連の操作・保存を確認 | 対象の公開版での結果。実施範囲と反映版を記録 |

実装変更は関連検証と全テストを行う。公開作業の完了は [リリース手順](../08_release_runbook.md) の確認まで必要。ローカルテスト成功をスマホ・公開環境の確認済みと扱わない。

## 対象ごとの証拠

| 対象 | 確認する内容 |
|---|---|
| データ生成 | env/ の入力、検証結果、generated.js との一致。旧 data/ 参照は修復済み |
| サーバー | API の応答、エラー、親子行、同じ requestId の再送 |
| 画面 | 一覧・絞り込み・作成・下書き編集・保存・詳細・戻る |
| 配色 | コントラストテストと必要な実機確認 |
| デプロイ | 既存 ID・版番号・push / deploy の結果、公開後の操作 |
| 文書 | 基準3文書との整合、参照先の存在、現状と履歴の区別 |

2026-10-24 の生成時 ENOENT は修復し、同日の npm test は全48件成功。過去のテスト件数やデプロイ番号を現在の PASS に流用しない。未実行の検証は未実行、未確認の公開状態は未確認と記録する。.git がないため Git 差分だけを証跡の条件にせず、実ファイルや比較結果を使う。
