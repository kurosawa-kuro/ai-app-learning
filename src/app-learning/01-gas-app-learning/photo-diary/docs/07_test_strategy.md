## 自動テストの役割

| ファイル（src/tests/） | 検証すること |
|---|---|
| architecture.test.mjs | 層の境界、GAS API の使用箇所、提供元の分離、色の配置 |
| contrast.test.mjs | UI の文字と背景のコントラスト |
| build-data.test.mjs | YAML・CSV の検証、生成結果との一致 |
| server.test.mjs | 業務 API、シート初期化、入力検証、保存・再送、提供元の差し替え |
| ui.test.mjs | 実際の HTML を jsdom で組み立て、画面操作を検証 |
| gas-mock.mjs | 上記で使う模擬 GAS。単独の製品機能ではない |

jsdom・模擬 GAS での成功は、実際の GAS やスマホでの動作を証明しない。実装変更時は関連する検証と全テストを行い、必要な回帰ケースを加える。テストを実装に合わせて弱めない。
