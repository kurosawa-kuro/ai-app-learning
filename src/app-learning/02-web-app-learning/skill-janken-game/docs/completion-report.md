## 今回の変更

- Geminiの短文＋任意1画像による下書き。既存の画像検証、全体AI許可、完全一致のモデル制限を使用する。
- `ai_requests` へ状態・結果・所有・入力ハッシュを永続化。同一要求の成功再取得、並行送信、タイムアウト、2分超過、7日保持期限、別ブラウザーからの取得拒否。
- 下書き生成・確認・本文への反映・破棄を投稿保存と分離。ネットワーク失敗時は同じ要求の状態取得だけを案内する。
- `UserReferences`、`ImageReferences.images()`、`RecoveryDataset` により投稿固有処理を分離。ユーザーディレクトリだけの復旧構成も検証。
- 投稿作成／編集のJSON応答を共通化、画像配信Controllerを分離。V9でAI台帳と画像種別NULL拒否を追加。既存ID・画像・設定を維持。
- バックアップ形式2で対象表一覧とFlyway版を照合。AI結果も対象に含める。過去形式は作成時のコードで復元する。
