# 5教材のUI/UX再検証・公開作業（2026-10-28）

## 対象と方針

実データのある画面をPlaywrightで操作し、1440×1000／390×844のスクリーンショットを撮影・目視確認する。固定応答のローカル検証と、公開先の実AI検証を分ける。不要な認証・監視・監査DBを追加しない。

## 発見と修正

| 発見 | 修正 | 確認 |
|---|---|---|
| 日記のタグがカンマ入力のみで多対多を操作しにくい | 最大5個のチェック選択、件数、複数タグのOR絞込み、タグ管理 | 3タグ保存・再読込、5個上限、名前変更後の関連維持、使用中削除をサーバーでも拒否、未使用削除 |
| タグのマスターがない | V12でUUIDのマスターと中間テーブルへ移行 | 既存関連を保持。名前変更はversionで競合確認 |
| 画像読込中にカードの高さが潰れ、画像がないように見える | 共通の固定画像枠・状態表示・再読込・拡大を日記に適用 | 公開先でデコード、故意の通信失敗→再読込を確認 |
| 拡大画像と閉じるボタンがスマホで横並び・縦書きになる | Picoダイアログのdisplay・min-width/min-heightを上書き | 390px内の余白、画像、ボタンを実画像で確認 |
| チェック印が見えづらい | ネイティブのチェック・ラジオ表示と選択背景 | スマホ画像を撮り直して確認 |
| 固定ヘッダー越しに本文が透ける | 不透明な背景 | スクロール状態の画像で確認 |
| 評価表の名前・見出しがスマホで途中改行 | 表内の改行抑制、横スクロール案内 | PC／スマホ、同点順位・編集・再集計 |
| 評価入力が長く、各項目へ移動しづらい | 数量項目のグリッド、保存操作を独立行、画面内リンク | 修正前後の画像、保存操作 |
| 英語・じゃんけんの利用者と左下表示が不一致 | Cookie・画面選択を揃え、切替イベントを教材へ反映 | 別ユーザー選択・再読込・表示一致 |
| 英語・じゃんけんの各機能まで長くスクロールが必要 | クイズ・会話・振り返り・履歴、対戦・セリフ・履歴へのリンク | 画面内リンクとスマホ画像 |
| 注文確認から数量を保ったまま戻れない | 確認画面に「数量を変更する」 | 2個＋1個を保持して戻り、1800円で再確認・確定・再送・取消 |
| 管理画面でDB接続を確認できない | 手動のDB接続確認 | 成功・所要時間、失敗時の秘密値非表示を単体試験 |
| Renderで日付が10/1/26になる | 日付をyyyy/MM/ddへ固定、コンテナーを日本時間へ | 公開先の評価編集リンクを再確認 |
| DBからUTCで返る履歴時刻が日本時間にならない | 履歴表示でAsia/Tokyoを明示 | UTCの15:05が日本の翌日00:05になる境界試験 |
| コピー元のCSVを教材固有データと誤認しやすい | 共通ユーザー・投稿ノートのみと画面に明記 | 管理画面の表示確認 |

## 公開先で発生した事象

- 写真日記のタグ管理・保存は成功。3画像の実Gemini生成で20秒タイムアウトが1回発生。画面は日本語の失敗案内を表示し、入力・画像を保持。自動再送なし。別の手動確認では実生成・手直し・3画像保存・再表示成功。最初の失敗を成功に数えない。
- 評価の公開試験は日付表記のローカル差で失敗。実績自体は保存されていた。テストの期待を曖昧にせず、アプリの表記を固定して再公開した。
- Renderのメンテナンスモードは無料サービスでは利用できずAPIが拒否。プラン変更は行わず通常デプロイで切り替えた。
- RenderのHobbyサービス数上限25件に到達。ショップとじゃんけんのサービス作成は未完了。他プロジェクトの削除・上書き・課金プラン変更は実施していない。削除可能な2サービスの指定をユーザーへ依頼中。
