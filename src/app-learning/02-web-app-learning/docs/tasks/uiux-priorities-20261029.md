## 公開する版の分離

公開4サービスは調査時点で `cdefa83`。作業ブランチには未公開の認証コード・V15があるため、`release/uiux-20261029` を `cdefa83` から作成し、今回のUIUX差分だけを反映した。認証コード・依存ライブラリー・DB移行の差分がないことを検査した。対象4サービスのRender自動デプロイは既に無効で、設定を変更せず特定コミットの手動デプロイを行った。[Render公式API](https://api-docs.render.com/reference/create-deploy)の `commitId` を使用した。

テスト設定の最終方針は接続プールを既定3件に維持し、Maven引数でテストコンテキストのキャッシュだけを1件へ制限する。V9からの移行試験は既存接続を保持してFlywayを動かすため3接続が必要。アプリ設定やテスト本体を変更して合格扱いにはしない。
