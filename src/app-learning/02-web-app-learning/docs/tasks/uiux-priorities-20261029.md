## 変更

1. じゃんけんのプレイヤー選択をページの対象者・合計・履歴と同時に更新する。処理中や結果不明の対戦を別人へ切り替えない。

共通の区画切替とユーザー切替前の取消可能なイベントはtemplateを含む6アプリのソースへ同じ差分を反映する。区画切替JSを配信するのは利用する3画面のみ。公開対象は今回の固有変更がある4教材。

## 公開する版の分離

公開4サービスは調査時点で `cdefa83`。作業ブランチには未公開の認証コード・V15があるため、`release/uiux-20261029` を `cdefa83` から作成し、今回のUIUX差分だけを反映する。認証コード・依存ライブラリー・DB移行の差分がないことを検査する。Renderの自動デプロイは既に無効で、設定を変更せず特定コミットの手動デプロイを行う。[Render公式API](https://api-docs.render.com/reference/create-deploy)の `commitId` を使用する。

テスト設定の最終方針は接続プールを既定3件に維持し、Maven引数でテストコンテキストのキャッシュだけを1件へ制限する。V9からの移行試験は既存接続を保持してFlywayを動かすため3接続が必要。アプリ設定やテスト本体を変更して合格扱いにはしない。
