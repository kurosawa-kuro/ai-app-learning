# 横展開前の課題・完了状況

2026-10-27更新。テンプレートの採用済み実装範囲を対象とする。古い「未実装」の棚卸しを現コード・検証結果で更新した。検証詳細は[完了記録](completion-report.md)、運用は[復旧手順](operations-runbook.md)を参照する。

本人に意味のある一つの課題でAIへの依頼・試行・結果確認を経験できることが教育の起点。提供者のサポートを有限に閉じるため、日常修正・障害確認・復旧をアプリ側へ整える。全教材・全技術の履修を求めない。

|---|---|---|
| P0-01 | 投稿編集・画像差替え | 本文／画像の維持・置換・解除、楽観ロック、DB／Storage失敗時の旧データ保持。PostServiceTests、BacklogIntegrationTests、画像ONのE2E |
| P0-02 | ユーザー名編集 | ID・アイコン・既定・投稿を保持し変更。入力検証、一覧・切替への反映をJava／E2Eで確認 |
| P0-03 | 完全バックアップ・復元 | DB・画像・設定・AI台帳、SHA-256、別スキーマ・別画像キーへの復元。実DB・Storageの13投稿／3ユーザー／5画像を照合 |
| P0-04 | 接続状態 | DB・Storage未設定／失敗／正常、画像禁止、環境表示、確認時刻と次の操作。OperationsTestsと管理E2E |
| P0-05 | 画像再試行 | 永続後片付けキュー、参照保護、元画像なし／取得失敗の区別。補償・再試行・表示を確認。バケット全体の未参照物を勝手に削除しない |
| P0-06 | 環境識別 | 環境・スキーマ・接続識別表示、シードの許可スキーマ制限・production拒否、通常起動では投入しない |
| P0-07 | 公開範囲 | localのループバック制限、productionのBasic必須・CSRF。PublicAccessTestsで匿名／誤資格情報の拒否を確認。公開先での確認はデプロイごとの運用手順 |
| P1-01 | 画像UI | 800pxフィード、contain、予約領域、拡大・Esc・戻る。PC／スマホと実画像を確認 |
| P1-02 | 検索・並び替え | タイトル・本文・投稿者・日時順、条件付きページャー・0件表示。Java／E2E |
| P1-03 | 未保存保護 | 離脱確認、JSON送信失敗時に本文・選択画像を保持。HTML再表示のファイル再選択制限を明記 |

| F2 | AI要求・下書き | 永続要求・成功再取得・重複拒否・結果不明・保持期限、採用／破棄／通常保存を分離 |

実装順は、変更前バックアップ → 共通境界整理 → AI要求の永続化・下書き → 制約修正 → 回帰試験 → 別環境復元・実画像受入 → 文書更新。検証結果を[完了記録](completion-report.md)に残す。

## 制作範囲へ戻さないもの

実課金集計、アプリ固有インポート、独自ログイン、音声、決済、POS、複数店舗、複数画像投稿、汎用会話エンジンは今回の実装予定ではない。各教材のカート・スキル・評価計算・問題管理もテンプレートの残作業へ混ぜない。Renderへのデプロイと公開先でのアクセス確認は、リリース時の運用であり、ローカル検証結果を公開済みと表現しない。
