# 教育用テンプレートの対応状況

2026-10-27、教育目的を超えた要求を廃止した。過去の不足表を全部実装することを目標にしない。[最小構成](educational-baseline.md)・[再発防止](education-scope-incident.md)を優先する。

| 対象 | 判断 |
|---|---|
| 投稿CRUD、画像、ユーザー、ページャー、CSV、設定 | 維持・回帰検証 |
| Gemini疎通・任意画像の下書き・モデル制限 | 維持、直近1件のセッション保持へ簡素化 |
| Basic認証、独自バックアップ／復元、運用監視画面 | 廃止。残作業に戻さない |
| Supabase Auth | 2026-10-28決定で導入予定・未実装（[ADR 0004](../../../../../docs/adr/0004-auth-gas-simple-web-supabase.md)）。Basic認証の復活ではない |
| DB監査ログ、AI永続台帳、期限切れ定期処理 | 実行コード削除。旧データは保持 |
| 全画面の接続バナー、不要な共通DB照会・JS配信 | 削除・対象画面へ限定 |
| CSS同梱漏れ | Git除外を修正、公開先の全CSS検査を追加 |
| 空データだけの性能確認 | 12投稿・4画像・複数ページで確認する受入へ変更 |

実装・試験・公開確認は[最小構成の検証記録](educational-baseline.md#検証記録)で区別する。未来の本番機能を暗黙の残作業として追加しない。
