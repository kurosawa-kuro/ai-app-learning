# 02 Webアプリ制作

> 2026-10-28：Web版AIをOpenAIへ移行中。現行の接続設定と検証状況は[OpenAI移行記録](docs/tasks/openai-migration-20261028.md)を参照。下記のGemini検証は移行前の記録です。

この全体案内は内部管理用です。利用者向けには[情報出口の分離方針](../docs/publication/README.md)に従い、選択した教材の公開用原稿を渡します。既存アプリのコード・仕様の正本は移動しません。

[01 GASでのアプリ入門](../01-gas-app-learning/README.md)に続く段階。AIへ要望を伝え、変更を試し、結果を確認する流れを、自分用・業務用のWebアプリ制作へ広げる。

提供者がコード・解説を作る順番では、この **02 Webを先に制作し、その後01 GASへ展開**する。ローカル起動・DB確認・自動テストを行いやすいため、仕様・実装・確認手順・解説を先に固める。受講順は01→02のままとする。詳しい方針は[横断設計](../docs/README.md)を参照する。

- [支援戦略](web-app-support-strategy.md)：対象者・本人のゴール・提供者が補助する範囲。
- [スターターテンプレート](template/README.md)：Spring Boot・Thymeleaf・Render・Supabaseの共通基盤。
- [横展開の必須手順](教育用アプリ横展開の残作業ゼロまでの実行計画.md)：5アプリともtemplateの中身を丸ごとコピーして開始し、必要箇所だけ追加・修正する。ダミーデータで画面と機能を先につなぐ。[AI作業指示](AGENTS.md)にも同じ必須条件を定める。
- [横展開前の課題](template/docs/improvement-backlog.md)：優先度・残課題・完了条件。
- [配布範囲と横展開の方針](../docs/feature-allocation.md)：3教材はGASと同じ基本機能で完成。じゃんけんはスキル・AIセリフ事前作成、ショップはカート経由注文まで。英語の問題管理画面は任意の応用。
- [目標と参考プロンプト](../docs/04_extension-catalog.md)：英語から資格学習、写真日記から旅行記など、小さく題材を変えて試す材料。

技術や教材の一覧をすべて習得することではなく、本人の目的に必要な一つのアプリを動かし、AIと改善を続けられることを目指す。

GAS・Webの両版で完成版を配布するのは、**写真日記・キャスト評価・英語訓練の3教材だけ**。じゃんけん・ショップを両基盤で同じ完成品に揃える要件は設けない。[配布対象とAI機能の対応表](../README.md)を参照する。
