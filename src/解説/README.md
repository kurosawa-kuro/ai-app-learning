# AIと一緒に学ぶための入門ガイド

このガイドでは、クロが取り組んでいる学習支援の目的、受講者それぞれに合ったゴール、教材の活用方法を紹介します。

## この取り組みで身に付けてほしいこと

この教材では、質問や依頼の内容によってAIを使い分けます。

| 何をするか | 使うもの |
|---|---|
| プログラムコードの意味を聞く、不具合を調べる、改造を頼む | Devin |
| アプリのプログラムからAIに問い合わせ、生成・採点・会話などを行う | OpenAI API |
| 集計・ファイル整理・文面作成などの業務自動化を相談・依頼する | Cursor |

2026-10-28にこの役割分担へ統一し、教材アプリのGemini利用は廃止する方針です。必要な準備は選んだ教材に合わせて案内します。

僕がこの取り組みを通して身に付けてほしいのは、**自分で目的を決め、AIを活用しながら学び、問題を解決する力**です。

題材としてプログラミングを扱いますが、学ぶ対象はプログラミングに限りません。身近な困りごとを見つけ、やりたいことを小さな作業に分け、AIに相談して試し、結果を確かめる。この経験を、日常の学習や仕事にも生かしてもらいたいと考えています。

AIは便利ですが、必ずしも正しい答えを返すとは限りません。最初から上手に質問できなくても大丈夫です。うまくいかなかったときは、期待した結果との違いを整理し、原因を調べたり、元に戻して別の方法を試したりします。

目指すのは、用意された教材を進める経験を足場に、自分に必要な課題を見つけ、AIと一緒に解決へ進めるようになることです。本人が考え、試行錯誤するほど、AIを使って実現できることも増えていきます。

プログラマーを目指す人も、身近なアプリを使ってみたい人も、事務作業を楽にしたい人も、自分の目的に合った入口から始められます。

## まずは、コンピューターとプログラムの話から

いきなりAIの使い方や細かな操作を説明するのではなく、身近な例を使って、次の順に解説します。

1. **コンピューターとは何か** — 情報を受け取り、決められた手順に沿って処理する道具として捉えます。
2. **プログラムとは何か** — コンピューターに「何を、どの順番で行ってほしいか」を伝える指示として捉えます。
3. **AIがある時代に、プログラミングを学ぶ意味** — やりたいことを整理し、AIに伝え、できたものを確かめるために、基礎を学びます。
4. **プログラマーを目指さない人が学ぶ意味** — 日々の作業を整理したり、繰り返しの処理を自動化したりするために役立てます。
5. **AIから学ぶということ** — 自分の理解に合わせて説明してもらい、試しながら学習を進める方法を体験します。

## 自分の目的に合った入口を選ぶ

用意している取り組みは、大きく分けて次の3つです。すべてを順番に受講する必要はありません。

| 取り組み | こんな人に | ゴールの例 |
|---|---|---|
| アプリを通じた学習（`app-learning`） | 身近なアプリを題材に、コンピューターやプログラムの仕組みに触れたい人。自分用・業務用のアプリを使いたい人 | AIと一緒に小さな変更を試し、結果を確かめる。目的に合ったアプリを使えるようになる |
| Javaを中心とした資格・実務学習（`java-career-learning`） | プログラマーの仕事に関心があり、基礎知識や実務につながる技能を学びたい人 | Javaの基礎や資格学習に取り組み、簡単なコードを自分で理解・修正できるようになる |
| 事務作業の自動化（`office-automation-starter`） | アプリ制作よりも、日々の事務作業を効率化したい人 | AIに作業を依頼し、集計・ファイル整理・文面作成などの結果を確認して活用する |

アプリを通じて学ぶ中でプログラマーの仕事に興味を持ったら、Javaの学習へ進むこともできます。最初から資格や仕事を目標にしている人は、その入口から始めて構いません。

導入では、入門者がつまずきやすい環境構築やアカウントの準備も支援します。教材に応じてGitHubアカウントを作らずに始める方法も選べます。PC・OS・必要な操作・アカウントは、[受講前の準備](記事/受講者向け_受講準備とサポート案内.md#受講前の準備)で確認します。

## テキストと動画で学ぶ

解説は、テキストと動画で提供する方針です。どちらも、伝える内容は同じです。

テキストは、自分のペースで読み進めたり、必要な箇所を読み返したりするために使えます。文章だけでは操作に不安がある人に向けて、合成音声による説明と、実際の操作・動作のデモを含む動画も用意します。

## 教材の活用方法

まずは「何ができるようになりたいか」を一つ決めます。例えば「表の集計を楽にしたい」なら、「列を確認する」「合計を出す」「手計算と比べる」に分け、最初の一つからAIに相談します。

学びの広がりには、次の5つの段階があります。

| 段階 | 取り組むこと | 成長を確かめる目安 |
|---|---|---|
| 1. 理解する | AIに説明してもらい、分からないことを聞く | 今回の目的と、何を試すかを自分の言葉で伝えられる |
| 2. 試してみる | サンプルの操作やコードを動かす | 支援を受けながらでも実行し、結果を確かめられる |
| 3. 確かめて直す | 期待と実際の違いを調べ、小さく修正する | 問題を伝え、修正後の確認や元に戻す操作ができる |
| 4. 自分で変更する | 条件を変えたり、別の用途に応用したりする | サンプルにない小さな変更を考え、結果を確認できる |
| 5. 自分で課題を決める | 身近な問題を選び、解決方法を考える | 目的・小さな作業・確認方法を決め、AIを使って進められる |

これは成長の見取り図です。全員が同じ順番で進む必要はなく、必要に応じて行き来します。自立には、難しい場面で人に相談する判断も含まれます。

## 最初の小さな成功を確かめる

環境の準備を終えたら、最初の30〜60分で試す課題を一つ選びます。時間は目安で、本人のペースや教材に合わせて調整します。

| 入口 | 最初に試す例 | できたことの確認 | 次の一歩の例 |
|---|---|---|---|
| アプリ学習 | 練習用のじゃんけんアプリで表示文言を一つ変える | 狙った表示に変わり、対戦も引き続き動くことを確認する | 小さなルール変更を考え、勝ち・負け・あいこの結果を確かめる |
| Java学習 | 短いサンプルを動かし、出力する文字を変える | 変更前に予想した文字が表示されることを確認する | 条件分岐や繰り返しを学び、短い処理を自分で修正する |
| 事務作業の自動化 | 架空の3行の表を、AIと一緒に集計する | 手計算の合計と一致し、元ファイルが残っていることを確認する | 自分の業務に似せた架空の表で、集計条件を変える |

初回は、支援を受けながらでも「希望をAIに伝え、試し、結果を比べる」を経験できれば十分です。時間内に終わらなければ、できた部分と残った問題を記録し、次の扱いを相談します。

説明を読んで納得したことと、実際にできたことは分けて振り返ります。非エンジニアは目的に必要な操作と結果の確認を、Javaの実務学習では自力でのコード修正も確かめます。[目的別の到達チェック](記事/受講者向け_AIと学ぶ進め方.md#目的別の到達チェック)を、試験ではなく成長の目安として使ってください。

## 慣れてきたら、自分の目的に合わせて改造してみよう

**英会話の学習アプリをAIに改造してもらい、資格試験の学習アプリに変える**のも、よいチャレンジです。

例えば、英語の出題・回答・採点・振り返りの流れを生かし、問題と採点基準を資格の学習内容に置き換えます。最初は自分で用意した1問から始め、正しい回答と誤った回答を入れ、信頼できる教材の正答・解説と比べます。正答率の記録や苦手問題の復習は、その後に必要なら追加する候補です。

最初からコードのすべてを理解する必要はありません。**何を再利用し、何を変え、何で結果を確かめるか**を自分で考え、AIに伝えることを大切にします。同じ考え方で、事務処理の集計条件や、Javaの練習課題も自分の用途へ広げられます。

改造は希望する人が選ぶ発展課題です。現在の教材に備わっている機能を確認し、一度に一つずつ変更します。[資格学習への改造例](記事/受講者向け_AIと学ぶ進め方.md#英語学習アプリを資格学習へ応用する例)には、依頼文と確認方法を載せています。

## 安心して試すために

AIの回答が間違うことや、修正後に別の動作が壊れることはあります。学習用のコピーで試し、「期待した結果」「実際の結果」「エラー文」を整理しましょう。改善しないときは変更を重ねず、元に戻すか相談します。詳しい手順は[AIと学ぶ共通ガイド](記事/受講者向け_AIと学ぶ進め方.md)を参照してください。

AIには、パスワード・個人情報・顧客情報・許可されていない業務情報を渡しません。架空のデータで練習し、出力は確認してから使います。

教材とコードは無料で提供する方針です。外部サービスは無料で試せる範囲を確認してから選び、有料利用は必要になったときに本人が判断します。無料枠の終了条件、利用量に応じた料金、自動更新、解約条件は[費用とサポートの案内](記事/受講者向け_受講準備とサポート案内.md)で確認します。

## コードも含めて無料で提供する理由

僕が教材をコードごと無料で提供できると考えているのは、皆さんがAIを学習の伴走役として活用することで、人によるサポートを必要な場面に絞れるからです。

想定しているのは、最初に数回の導入説明を行い、その後は質問への対応や、必要に応じたZoomなどでの短い相談を組み合わせる形です。取り組む課題や支援の回数・時間・期間・相談窓口は、始めるときに決めます。AIで解決できないときや、操作の影響が判断できないときは、[相談の目安](記事/受講者向け_受講準備とサポート案内.md#人に相談する目安)を使ってください。

日々の疑問をAIに聞き、自分でも試してもらえるようになれば、僕がすべての操作を継続して支える必要はなくなります。支援の範囲と負担の見通しが立つことで、無理なく教材を提供し続けられます。

皆さんには、自分のペースで学びを続ける力を。僕には、続けられる範囲で支援する仕組みを。その両方を、AIと一緒に実現していきたいと考えています。
