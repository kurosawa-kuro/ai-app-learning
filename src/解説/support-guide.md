# 受講準備・費用・サポートの案内

[入門ガイド](README.md)から学習を始める前に、選んだ課題に必要な準備と支援の範囲を確認します。具体的な契約条件や提供内容は、利用するサービスと教材ごとに決めます。

## 受講前の準備

2026-10-28の役割分担に合わせて、コードについての質問・改造にはDevin、プログラムからのAI呼び出しにはOpenAI API、業務自動化の質問・作業にはCursorを準備します。教材アプリのGemini利用は廃止する方針です。選んだ教材と行う作業に必要な準備を案内します。

| 用途 | 準備で確認すること |
|---|---|
| コードの質問・改造（Devin） | 利用アカウント、教材リポジトリへのアクセス、作業対象、変更の反映・確認方法 |
| アプリからAIを呼ぶ機能（OpenAI API） | API利用の準備、キーの発行・保管、対象アプリへの設定、接続と利用額の確認方法 |
| 業務自動化（Cursor） | アカウント、インストール・サインイン、サンプルを開く場所、依頼と出力確認の方法 |

操作や改造の実習は、PCとインターネット接続を用意して進める想定です。スマートフォンでの閲覧・体験と、PCでの編集作業は分けて確認します。

ブラウザーを開く、文字を入力する、コピーして貼り付ける、ファイルを保存して開く、といった操作を使います。不慣れな操作があれば、最初に一緒に練習します。

| 入口 | 開始前に確認すること |
|---|---|
| アプリ学習 | 使う教材と版、対応するPC・ブラウザー、必要なアカウント、練習用のコピーと戻し方。GASを編集する場合はGoogleアカウント等、選んだ手順に必要なものを確認する |
| Java学習 | PCのOS、教材が指定するJava実行環境・編集方法、最初のサンプルを動かす手順。提供者が準備する範囲と、本人が行う操作を決める |
| 事務作業の自動化 | 現行教材はWindows向け。Cursorを使うための準備とサインイン、サンプルファイルの保存場所を確認する。PythonやNode.jsの追加導入を前提にしない |

GitHubの利用は全員共通の受講条件ではありません。教材の取得方法や公開方法によって必要なアカウントは変わるため、選んだ教材の導入手順で確認します。

最初の30〜60分の課題は、環境の準備が終わってから取り組む目安です。インストールやアカウント準備の時間を一律に含めず、準備で止まったときは課題の難しさと分けて対応します。

## 無料で試す範囲と有料利用

教材とコードは無料で提供する方針です。外部サービスの利用料、資格の受験料、個別支援の条件は別に確認します。教材が無料であることと、外部サービスやすべての支援が無条件に無料であることは分けて案内します。

導入時には、選んだ課題を無料で試せる範囲を確認します。無料枠が足りなくなったら、いったん止め、待つ・課題を小さくする・有料利用を選ぶなど、利用可能な選択肢を確認します。

有料利用を始める前に、次を確認します。

| 確認すること | 確認の内容 |
|---|---|
| 無料枠の範囲と終了条件 | 利用回数・容量・期間の上限、上限到達時に停止するのか追加料金が発生するのか |
| 料金の仕組み | 定額か、利用量に応じた従量課金か。最低料金、通貨、税、追加料金の条件 |
| 使い過ぎへの対処 | 利用額の確認方法、通知や上限設定の有無。通知だけか、利用を止める上限か |
| 更新と解約 | 自動更新の有無、解約手順と期限、解約が反映される時点、残額・保存データの扱い |
| 本人の選択 | 何のために有料にするか、予算をいくらにするかを決め、本人が申し込む |

特定のサービスの金額は入門ガイドに固定しません。具体的に案内する際は、サービス名・プラン・無料枠・想定利用量・費用・公式情報のURL・確認日を別の料金案内にそろえます。この文書は料金表ではなく、最新料金を確認済みという意味でもありません。

## 人に相談する目安

次のような場合は、一度作業を止めて、開始時に決めた窓口へ相談してください。

- 同じ失敗を繰り返し、次に何を確かめればよいか分からない。
- 修正したら別の動作が壊れた、または元に戻せない。
- AIの説明や操作の意味が分からず、影響を判断できない。
- データの削除・上書き、個人情報、課金、外部公開に関わる判断が必要になった。

AIで何回か試すことを、相談するための条件にはしません。不安な操作は、実行する前に相談して構いません。

相談には「目的」「教材・環境」「期待した結果と実際の結果」「エラー文」「試したこと」を添えます。[共通ガイドの記入例](learning-guide.md#うまくいかなかったとき)を使い、秘密情報は取り除いてください。

## 始めるときに決める支援の範囲

導入説明、操作の補助、質問対応、必要に応じたZoomなどでの相談を組み合わせます。具体的な回数や対応時間は、課題と本人の状況に合わせて決めます。

| 項目 | 決めておく内容 |
|---|---|
| 今回の課題と成果 | 一つの課題、期待する結果、確認方法 |
| 準備と役割 | 環境やアカウントを誰が準備するか。AI・本人・提供者がそれぞれ行うこと |
| 対応の枠 | 回数、1回の時間、開始・終了日、質問窓口、返信の目安、質問対応量、費用の有無 |
| 不具合の扱い | 教材・環境の不具合を扱う範囲と期間、本人の作業との切り分け |
| 追加の要望 | 別機能・別教材・継続運用の相談方法と、別に範囲を決めること |

## 終了時に渡すものと、その後

終了時には、できたことと支援した部分、再利用できる依頼文、確認方法、元に戻す手順、残った問題を一緒に整理します。

課題が終わっていれば、合意した支援を終了し、本人が希望する次の学びへつなげます。時間や期間が終わっても課題が未達なら、未達のまま理由を記録し、課題を小さくする・準備を直す・別枠で再開する・いったん終了する、のどれにするかを相談します。

本人が学習を続ける期間と、提供者が対応する期間は分けて決めます。英語学習アプリを資格学習へ変えるなどの発展課題も、支援を希望するときは新たに範囲を相談します。

提供者の内部記録には、既存の[初回支援シート](../../docs/templates/ai-pairing-session.md)を使います。
