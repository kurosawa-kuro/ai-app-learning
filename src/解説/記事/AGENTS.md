# 解説記事フォルダーの編集ルール

ユーザー指定により、このフォルダーでは日本語のファイル名を使う。リポジトリ共通の英小文字・ハイフン命名の例外とする。

- 文書名は `対象読者_内容.md`。対象読者は `受講者向け` または `作成者向け` とする。
- 内容は日本語で、案内・進め方・設計・制作仕様・候補・進捗など、その文書の役割が分かる名前にする。
- `README.md` と `AGENTS.md` は例外。連番は付けず、利用順序はREADMEで示す。
- 先頭見出しはファイル名の拡張子を除き、`_` を `：` に置き換える。
- 改名・移動時は参照リンクとREADMEの一覧を更新し、リンク先の存在を確認する。
- 詳細は [READMEの命名規則](README.md#ファイルの命名規則)に従う。
