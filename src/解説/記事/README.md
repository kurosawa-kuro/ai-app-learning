# 導入サポートと記事・動画の制作設計

クロが、導入サポートと、それを支える記事・動画を制作するための入口です。受講者向けの本文は、この設計をもとに別途作ります。

まず、**共通のDevin基本操作編と、一つの教材の使い方編・改造編**を作り、実際のサポートで確かめます。日々の作業と進捗は[解説作成者側メモ](解説作成者側メモ.md)に記録します。

## 文書の役割

| 文書 | 管理する内容 | 開くタイミング |
|---|---|---|
| このREADME | 全体方針、サポートの組み立て、教材の参照先 | 方針を確認するとき |
| [記事・動画の制作仕様](materials-design.md) | 作る資料の範囲、記事と動画の対応、完成の確認方法 | 原稿・動画を作るとき |
| [受講準備・アカウント・費用](learner-preparation.md) | 必要な登録、課金箇所、Devinでの教材取得、Windows向け補足 | 準備案内を作るとき |
| [つまずき・懸念候補](learner-concerns.md) | 説明漏れを探すための候補一覧 | 手順を試す前後 |
| [解説作成者側メモ](解説作成者側メモ.md) | 制作順序、対象の選定、進捗、次の作業、試行記録 | 作業の開始時・終了時 |

方針はこのREADME、制作仕様は各文書、進捗や一時的な気づきは作成者側メモへ記録します。確定した変更は該当文書へ反映し、メモだけに残さない運用にします。

## 制作の前提

提供者の見立ては、**AI・使えるコード・導入記事・動画が揃えば、1回30分のサポートで始められる**というものです。30分は制作上の仮説であり、全員に十分と実証された時間ではありません。

3回×30分の枠は、一度説明を受けた後も相談できる安心のために用意します。記事・動画は内容別に作り、サポート回数を章立てにしません。準備・当日の説明・延長にかかった時間を分け、実際の負担を確認します。

この設計の中心はアプリ教材の導入です。業務自動化はCursor、資格・実務学習はその目的に合う課題と成果確認を使います。全員に同じ教材・ツール・学習順を課しません。アプリ教材の受講順はGAS → Web、提供者の制作・検証順はWeb → GASです。

## AIの役割分担

2026-10-28確定の[ADR 0003](../../../docs/adr/0003-ai-service-roles.md)に従います。

| 質問・依頼 | 使用するもの | 使い方 |
|---|---|---|
| プログラムコードについての質問・改造 | Devin | 受講者が説明・調査・変更を依頼し、結果を確かめる |
| プログラムコードからAIへの質問 | OpenAI API | アプリが生成・採点・会話などを依頼する |
| 業務自動化についての質問・作業 | Cursor | 受講者が集計・ファイル整理・文面作成などを依頼する |

教材アプリのGemini採用は廃止します。方針の確定と各教材の移行・動作確認は分け、現行の実装状況は各教材の正本で確認します。提供者の開発ツールと、受講者に案内するツールも区別します。

## サポートの組み立て

| 枠 | 扱うこと | 確認すること |
|---|---|---|
| 初回 | 教材の説明と使い方 | 何ができるかを理解し、基本操作を試して結果を確認できたか。後日開く場所と相談先が分かるか |
| 2回目 | Devinを使った小さな改造 | 希望を伝え、変更を反映し、期待した結果と比べ、戻し方を確認できたか |
| 3回目 | 未解消の疑問・不安・つまずきへの対応、または改造結果のレビュー | 残った問題、変更の意図と動作、元の基本操作への影響、残件の次の扱いを確認できたか |

初回の基本進行は「本人の目的・不安を確認 → 教材を説明 → 一緒に基本操作と結果を確認 → 再開方法と次の改造を案内」です。本人が支援を受けながら経験できればよく、暗記や改造までを全員の初回条件にはしません。説明が終わったこと、本人ができたこと、本人に残る不安を分けて記録します。

使い方をつかみ、本人が改造を希望し、双方の時間が取れる場合は、初回の後半から延長して2回目の内容へ進めます。延長時間は別に記録し、その後の枠は疑問や次の変更に合わせます。案内した残りの相談機会は維持します。

3回目は予備です。問題がなくても改造結果のレビューに使えますが、利用を必須にせず、専用の講義・記事・動画は作りません。相談前にAIで何度も失敗することも求めません。解消できない問題は原因と次の扱いを残します。

予約方法・利用期間・回の間の窓口・対応範囲・費用・不具合の扱いは、提供前に具体化します。[受講準備・費用・サポートの案内](../support-guide.md)と[初回支援シート](../../../docs/templates/ai-pairing-session.md)へ揃えます。

## 教材リポジトリ

当面は [kurosawa-kuro/ai-app-learning](https://github.com/kurosawa-kuro/ai-app-learning) を使います（2026-10-28時点の方針）。後日変更する可能性があるため、制作資料の参照先はここに集約します。受講者へ渡す原稿・動画にも参照先をまとめ、変更時に差し替えます。

アプリ教材のコードはDevinのクラウド環境で取得・改造します。Windowsへのダウンロード・解凍は標準の必須条件にしません。取得、変更の保存、GAS／Webへの反映は別の操作として、[受講準備](learner-preparation.md#教材をdevinの環境へ取得する)で整理します。
