更新日：2026-10-28

## 現在地と次にやること

**制作設計を5文書へ整理済み。次は、最初に扱う対象者・教材・基本操作・小さな改造を一組選び、手順を通して確認する。**

この記事群の専用原稿・動画・実機試行は、完成物と記録をまだこのメモへ紐付けていません。以下の「未確認」は、既存の成果物が存在しないという意味ではありません。確認できたものからリンクと状態を更新します。

| 項目 | 現在の記録 |
|---|---|
| 最初の対象者・本人の目的 | 未選定。個人情報ではなく、制作に必要な対象像・目的を記す |
| 教材・版 | 未選定 |
| 初回に試す基本操作・期待結果 | 未選定 |
| 最初に試す小さな改造・期待結果 | 未選定 |
| 開始時の障壁と支援する範囲 | 対象を選んで確認する |
| 次の作業 | 上記を選定し、既存の教材・原稿・動画の有無を確認する |
| 判断待ち・作業が止まる理由 | 現時点では対象の選定待ち |

## 制作物の進捗

状態は「未確認 → 未着手／作業中 → 原稿済／収録済 → 手順確認済 → 試行済 → 提供可」を目安に、実際に確認できた段階を記します。完成物リンク・確認日・残件がないものを、提供可にはしません。

| 制作物 | 記事 | 動画 | 完成物・確認記録 | 次の作業 |
|---|---|---|---|---|
| 教材の説明と使い方編 | 未確認 | 未確認 | 未登録 | 対象教材を選び、既存素材を確認 |
| 共通のDevin基本操作編 | 未確認 | 未確認 | 未登録 | 対象教材への接続から質問・再開まで通す |
| 同じ教材の改造編 | 未確認 | 未確認 | 未登録 | 最初の変更と確認・戻し方を選ぶ |
| 受講者向けの準備・費用案内 | 設計整理済み | 必要箇所を本編へ含める | [準備設計](受講準備・アカウント・費用.md) | 選んだ教材に必要な項目を抽出 |
| 当日の進行メモ・終了後の案内 | 方針整理済み | 対象外 | [サポート構成](README.md#サポートの組み立て) | 当日使うリンク・確認項目を具体化 |

3回目専用の教材は制作対象にしません。必要な相談・レビューのために、既存資料と受講者の改造結果を使います。

## 制作を進める順序

| 段階 | 作業 | 残すもの・完了の目安 |
|---|---|---|
| 1. 対象を絞る | 一人の目的、一つの教材、基本操作、小さな改造を選ぶ | 上の選定欄と[初回支援シート](../../../docs/templates/ai-pairing-session.md)の目的・準備・支援枠 |
| 2. 手順を通す | 教材利用とDevinでの改造をそれぞれ通し、本人／提供者の作業を分ける | 版・リンク・操作・期待結果・戻し方・準備時間。未確認箇所も残す |
| 3. 最小原稿を作る | 使い方編・Devin基本操作編を整え、同じ教材の改造編へ進む | [制作仕様](記事・動画の制作仕様.md)に沿った原稿、当日の進行、終了後の案内 |
| 4. 動画を作る | 確認済みの教材と原稿で、同じ操作を収録する | 記事の見出しに対応する動画と参照先 |
| 5. 実際に支援する | 一式を使い、初回30分の想定を試す。必要なら延長・次回を使う | 下の試行記録、できたこと、残件と次の扱い |
| 6. 直して広げる | 止まった箇所を修正し、使えた共通説明を次の教材へ再利用する | 改訂箇所と再確認結果。次の対象でも最初の体験を確認 |

アプリ教材の実装・検証は各教材の正本に従い、提供者はWeb → GASの順に進めます。全教材の原稿・動画を同時に作り始めません。

## 試行記録

試行のたびに次の表をコピーします。初回の教材利用と、改造を扱う回の達成を分けて記録します。

| 項目 | 記録 |
|---|---|
| 日付・教材・版・使った記事／動画 | 未記録 |
| 実施内容 | 教材利用／Devin基本操作／改造／相談・レビュー |
| 準備時間・手伝ったこと | 未記録 |
| 当日の時間・改造等の延長時間 | 未記録。延長分を30分の実績に含めない |
| 本人ができたこと・提供者が補助したこと | 未記録 |
| 操作が止まった箇所・長い説明・不安 | 未記録 |
| 初回後に自分で再開できたこと | 未記録 |
| 残件・原因・次の扱い | 未記録 |
| 直す資料・箇所・再確認方法 | 未記録 |

30分で終わらない場合は、準備・説明・操作・課題の大きさのどこに原因があるかを確認します。課題を小さくする、手順を直す、補足を加える、支援の進め方を変える、のうち有効な対応を選びます。必要な体験を省いて時間だけを合わせません。
