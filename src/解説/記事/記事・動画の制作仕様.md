# 記事・動画の制作仕様

[制作設計の入口へ戻る](README.md)／[作成者側メモ](解説作成者側メモ.md)

最初に制作するのは、共通のDevin基本操作編と、一つの教材の使い方編・改造編です。この記事群をサポート当日の説明と、後日の読み返しに使います。

## 制作物と到達点

| 制作物 | 説明する内容 | 受講者と確認すること |
|---|---|---|
| 教材の説明と使い方の記事・動画 | 目的、できること、開く場所、基本操作、結果、再開方法 | 教材を開き、基本操作を試し、結果を確認できる |
| Devin基本操作の記事・動画 | ログイン、教材への接続、質問、返答・作業状況の確認、停止、再開 | 教材について一つ質問し、追加質問でき、後日続きを開ける |
| 教材を改造する記事・動画 | 小さな希望の伝え方、変更の保存・反映、動作確認、修正依頼、戻し方 | 一つの変更を試し、期待結果と比較できる |
| 当日の進行メモ・終了後の案内 | 支援する操作、確認事項、参照リンク、相談先 | 次に何を開き、何を試し、どこへ相談するか分かる |

コード・サンプルは、基本操作と変更結果を比較できる状態で用意します。対象教材の実装・検証状況を確認し、構想や原稿の完成だけで動作確認済みとは扱いません。

## 教材の説明と使い方編

1. 本人の目的と、この教材でできることをつなげる。
2. 必要な準備と教材を開く場所を案内する。
3. 最初に試す基本操作を一つ示す。
4. 期待する結果と、確認する場所を示す。
5. 後日再開する方法、記事・動画、相談先を示す。

[入門ガイド](../README.md)から、今回の体験に必要な基礎説明を選びます。コンピューター・プログラム・AIから学ぶ意味を説明する深さは本人に合わせ、詳しい内容は補足へつなげます。

準備・課金は[受講準備](受講準備・アカウント・費用.md)のうち対象者に必要な項目へ案内します。アプリ内AIが必要な教材では、OpenAI APIの設定と接続確認も含めます。

## Devin基本操作編

教材の内容を考える前に操作で止まることを減らすため、共通の記事・動画として独立させます。最初の練習は「この教材で何ができるか説明して」と聞く程度にし、コードの変更は改造編で扱います。

| 操作 | 記事・動画に用意する内容 |
|---|---|
| 利用開始 | アカウント・ログイン、利用条件・料金を確認する場所 |
| 教材へのアクセス | GitHubとの接続、リポジトリと教材の指定、Devinの作業環境への取得 |
| 最初の質問 | 入力場所、質問例、送信、返答の確認 |
| やり取り | 聞き直し、Devinからの質問への回答、意図の訂正 |
| 作業中の確認 | 状況の見方、待っている理由や問題の確認、必要なときの停止 |
| 結果と再開 | 回答・成果物・会話の場所、次回続きを開く方法 |

基本操作編はDevinを初めて使う前に案内し、必要なら当日も一緒に確認します。操作支援の時間も記録します。独立した資料を作ることをサポート回数を増やす理由にはしません。

## 改造編

1. 使ってみた感想や疑問から、変えたいことを一つ選ぶ。
2. Devinに目的、対象リポジトリ・教材・版、変えたい点、残したい動作、確認方法を伝える。
3. 変更内容を確認し、受講者の保存先へ保存する。
4. 対象教材の手順でGAS／Webへ反映する。
5. 変更後の期待結果と元の基本操作を確認し、必要なら修正を依頼する。
6. 戻し方と次回の再開方法を残す。

DevinがPC上のファイルや教材の内容を自動で知っている前提にせず、接続・指定・添付するものを明確にします。Devinに任せる作業と、本人が行う設定・操作は、対象教材の環境で確認してから記事にします。

改造後には、使った依頼文・結果の確認方法・戻し方を渡します。別用途への応用は選択肢として扱い、初回の必須課題や新規教材の追加制作へ広げません。

## 記事と動画の揃え方

- 記事は操作を探して読み返せる構成、動画は同じ操作を画面で追える構成にする。見出しと動画の区切りを対応させる。
- 記事・動画の全編事前視聴を参加条件にはしない。必要な箇所へ当日も案内できるようにする。
- 具体的な画面名・操作・料金・連携方法は、制作時の公式資料と実際の画面・対象教材で確認する。
- 最初の試行に必要な動画から収録する。凝った編集や全教材分の制作は、導入の流れを確かめてから進める。
- 業務自動化の資料では、Cursorへの依頼、出力の正確さ、元ファイルの保全を扱う。アプリ改造編をそのまま流用しない。

## 完成の確認

原稿・動画を作れたことと、受講者が使えたことを分けて[作成者側メモ](解説作成者側メモ.md)へ記録します。

- 提供者が、受講者へ渡す材料だけで基本操作と改造の手順を通せる。
- 操作・期待結果・確認方法・戻し方が揃い、必要なリンクを開ける。
- 記事と動画の説明対象・画面・区切りが対応している。
- 受講者が初回後に開く入口から、教材・記事・動画・相談先へたどれる。
- 未確認の操作や残件が明記され、提供前に対応するものが決まっている。
